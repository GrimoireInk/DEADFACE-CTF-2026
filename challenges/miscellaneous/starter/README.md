## 2. Challenge Objective

The objective is to familiarize competitors with the event and introduce the standard DEADFACE CTF flag format.

Unlike traditional cybersecurity challenges, the Starter task does not require technical investigation, exploitation, cryptography, or reverse engineering.

The flag is explicitly included in the challenge description.

## 3. What Is a CTF Flag?

In a Capture the Flag competition, a *flag* is a specially formatted string submitted to a scoring platform to demonstrate completion of a challenge.

DEADFACE CTF uses the following general format:

`deadface{flag_content}`

Flags are usually discovered by solving cybersecurity problems, but this introductory challenge supplies an example directly.
